# Brand assets

The MARS mark is an acorn with incoming stream lines.

- `mark-acorn.svg`: source artwork.
- [`MarsMark.jsx`](../frontend/src/components/MarsMark.jsx): the UI component, adapted for small sizes.
- [`frontend/public`](../frontend/public): favicon and app icons.

Keep the mark legible at its displayed size. MARS is independent of the Apache
Software Foundation; its branding must not imply endorsement.
